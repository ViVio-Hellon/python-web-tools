# モード一覧

資材選択は**入力によって挙動が変わります**。何がどう変わるのかを1か所に
まとめます。現場からの「なぜこの結果になったのか」に答えるとき、まずここを
読んでください。

VBA原文(`総合ツール` の `MaterialMasterForm` ほか)と突き合わせた結果も
併記します。**思想が食い違っているものは「差」の欄に書きます。**

---

## 全体像

モードは大きく3つの層に分かれます。層が違うものは同時に効きます。

| 層 | 何で決まるか | 誰が決めるか |
|---|---|---|
| **受注の性質** | 引いたロット・受注の中身 | 自動(人は変えられない) |
| **包装仕様NO・寸法** | 受注の包装仕様NO と SIKALOT の寸法。**一部は表(マスタ管理で直せる)で決まる** | 自動(1P0113・プロテックは手で強制できる) |
| **選び方の好み** | 利用者が押す | 人(押しっぱなし) |

### 表で発火条件を決めるモード(VER4.8.56〜)

次の2つは、**発火条件をプログラムではなく表(梱包資材マスタの中)で持ちます。**
マスタ管理で行を足す・直すだけで、プログラムを直さずに条件を増やせます。

| モード | 表 | マスタ管理での名前 | 何を決めるか |
|---|---|---|---|
| プロテック | `プロテック条件` | プロテック条件 | どの包装仕様NO・ｵｰﾀﾞｰ寸法でプロテックにするか |
| 1P1185(パレット限定) | `パレット限定条件` | パレット限定条件(1P1185モード) | どの包装仕様NO・取引先・寸法で、**どのパレットに決め打つか** |

設定のしかたは [5. 表で決まるモードの設定方法](#5-表で決まるモードの設定方法) にまとめます。

## 1. 受注の性質で決まるもの

### EX受注

| | |
|---|---|
| 決まり方 | 仕掛受注の `EX_輸出区分` が空でない |
| 変わること | 帯に `EX` が出る / 倉庫送信で**発注コード・単位・発注数を空で送る** |
| こちら側 | `lot_service` が `is_ex` を立て、`work_context` と選定セッションが持つ |
| VBA | `SetExOrder` / `g_SendRows(r).isExOrder` |
| 差 | **なし** |

EXの実データは別の職場から届き、そちらが優先されます。こちらからは
「EXである」と分かる合図(品名 `EX`)だけを送ります ── 中途半端な値を
入れると、届いた側の突き合わせで混乱するためです。

VBAの `frmSendConfirm.btnSend_Click` も、EX行だけ発注数の検証を飛ばして
空欄で送っていました。ここも同じです。

## 2. 包装仕様NO・寸法で決まるもの

**4つあります。** どれも受注の包装仕様NO(`lblOdr(1)`)を見ます。プロテックと 1P1185 は
**寸法も**見て、条件は**表**で持ちます。

### 1P0113(裸梱包)

| | |
|---|---|
| 決まり方 | 包装仕様NO = `1P0113`、**または**「1P0113 強制」がON |
| 変わること | パレットもボードも使わない。溝切角材と松板だけで組む |
| こちら側 | `special_packaging.is_1p0113` / `force_1p0113` |
| VBA | `Apply1P0113Mode` / `m_force1P0113` |
| 差 | **なし**(強制トグルの扱いも同じ) |

資材は `松板角材` テーブルから寸法帯で引きます。松板の丈(A値)は製品丈で
4段階に分かれます(949以下→製品丈 / 1800以下→950 / 2400以下→1600 / それ以上→2330)。

### プロテック(条件は表 `プロテック条件`)

| | |
|---|---|
| 決まり方 | 表 `プロテック条件` の**どれか1行に当たる**、**または**「プロテック 強制」がON |
| | 1行 = 包装仕様NO **かつ** SIKALOT の**ｵｰﾀﾞｰ**板厚・板幅・板丈の範囲(空の欄は見ない。小数のまま比べる) |
| 初期値 | `1P1216` / `1P1211`(包装仕様NOだけ)・`1P1125`(ｵｰﾀﾞｰ厚 3.0〜15.0)・`1P1255`(ｵｰﾀﾞｰ厚 12.0 かつ 幅 1075〜1081・丈 2332〜2338、**または** 幅 1072〜1078・丈 2262〜2268) |
| 変わること | ボード種別が「プロテックボード」に切り替わる。**上用は下用と同じボードを強制**。幅は**製品幅基準・マイナスのみ・超過禁止**、許容は**上下共用で -10mm**。配置・切断依頼書もプロテックの挙動 |
| 帯 | 【プロテックボードオーダー選択中】(強制なら「(強制)」が付く) |
| こちら側 | `special_packaging.protec_state` → `ProtecState(is_protec, is_1p1216, forced, rule)`。条件は `protec_rules`、許容は `board_selection_protec.PROTEC_TOLERANCE` |
| VBA | `CheckAndSetProtecMode`(`cond2`)/ `mIsProtecMode` |
| 差 | **条件を表にした・寸法の条件と強制トグルを足した・許容を全部 -10mm にした**(VBA は包装仕様NO 3つの決め打ち、許容は 1P1216 だけ -10mm) |

**許容の移り変わり(記録):** VER4.8.58 までは **`1P1216` だけ許容が違いました**(コーミ金属)。
幅の許容はマイナス10mm、それ以外のプロテックはマイナス80mmでした。VER4.8.59 から、
現場の声で**どのプロテックも上下共用で -10mm** にそろえました。

「プロテック 強制」は 1P0113 強制と同じく、**ロットを切り替える・「やり直す」で解除**されます。
押したとき選定済みのボードは外します(前のモードの前提で選んだものなので)。

かつてVBAは「納入先に `ｶ)ﾏﾂｼﾀｼﾖｳﾃﾝ` を含む」も条件に入れていましたが
(`cond1`)、**廃止済み**です。こちらも移植していません。

### 1P1185(パレット限定。条件は表 `パレット限定条件`)

| | |
|---|---|
| 決まり方 | 表 `パレット限定条件` の**どれか1行に当たる**(並び順の小さい行から、最初に当たった行) |
| | 1行 = 包装仕様NO **かつ** 取引先名称に含む文字 **かつ** **製造**板幅・板丈 **かつ** **ｵｰﾀﾞｰ**板厚・板幅・板丈(どれも空の欄は見ない) |
| 初期値 | 包装仕様NO = `1P1185`・取引先名称に `ﾅﾒｶﾜｱﾙﾐ` を含む・製造板幅 1242〜1249・製造板丈 1242〜1249 → **タイト 1300×1300**(前の決め打ちと同じ) |
| 変わること | パレットを、当たった行の**業界(空なら見ない)・パレット幅・パレット丈**だけに絞る(一覧・自動選定とも) |
| 帯 | 【1P1185モード タイト 1300×1300 限定表示】(当たった行の包装仕様NO・パレットを出す) |
| こちら側 | `special_packaging.check_1p1185_mode` → `Mode1P1185State(is_1p1185, industry, pallet_width, pallet_length)`。条件は `pallet_limit_rules` |
| VBA | `CheckAndSet1P1185Mode` |
| 差 | **条件と決め打つパレットを表にした・オーダー寸法でも見られるようにした**(VBA は決め打ち。VER4.8.58〜、オーダーの列は VER4.8.60〜) |

製造板幅・丈は**整数に切り捨ててから**比べます(VBA・前のプログラムと同じ)。ｵｰﾀﾞｰ寸法は小数のまま比べます。

### 2つの表の両方に当たるとき

**プロテック条件とパレット限定条件は別々に当たります。** 両方に当たるロットは、
プロテック(ボード)**かつ**パレットはその行の寸法だけになります。帯には両方を出します
(例:「【プロテックボードオーダー選択中】【1P1255モード 1100×2500 限定表示】」)。

### 上下共用(ザラ板など)

| | |
|---|---|
| 決まり方 | 使用保護材がアングル以外に確定したとき |
| 変わること | アングルの欄を出さない。上用キャンバスを隠し、上下で同じボードを使う |
| こちら側 | `SelectionPresenter.is_shared_board_mode` |
| VBA | `m_lastHosozai` / `ShowAngleControls` |
| 差 | **画面上の扱いだけ広い**(下記) |

**プロテックも画面上は上下共用として扱います。** 上下とも同じボードを
使う点で同じだからです ── ただし**選定アルゴリズムでは別の分岐**で、
プロテックは許容幅での判定が要ります。画面の都合と選定の都合を混ぜない
よう、`selection_flags` は `is_protec_mode` を個別に渡しています。

## 3. 利用者が押して切り替えるもの

### 押しっぱなしのもの(ロットを切り替えても解除されない)

#### 疲労度優先

| | |
|---|---|
| 決まり方 | 利用者が押す(帯にチップが出る) |
| 変わること | 選定が「取り出す手間」を加味する。距離と面積(と本数)でスコア化 |
| こちら側 | `SelectionSession.fatigue` |
| VBA | `mFatigueMode` / `mFatigueMapLower` `mFatigueMapUpper` |
| 差 | **なし**(式は `modFatigueCore` の統一式と一致) |

**効いていることが画面のどこにも現れない**ので、帯にチップを出しています。
在庫考慮は候補一覧に「(在庫考慮)」と出るため、そちらには出しません
(同じものを2か所に出さない)。

#### 在庫考慮

| | |
|---|---|
| 決まり方 | 利用者が押す |
| 変わること | 在庫が薄いボードの点を下げる(看板マスタの「欲」を見る) |
| こちら側 | `board_scoring` の `stock_aware` |
| VBA | 同名の分岐 |
| 差 | **なし** |

### 強制(ロットを切り替える・「やり直す」で解除される)

資材選択の右上、モードバーの隣に並んでいます。

#### 1P0113 強制

| | |
|---|---|
| 決まり方 | 利用者が押す |
| 変わること | 包装仕様NOに関わらず 1P0113 として扱う |
| こちら側 | `force_1p0113` |
| VBA | `m_force1P0113` |
| 差 | **なし** |

#### プロテック 強制

| | |
|---|---|
| 決まり方 | 利用者が押す |
| 変わること | 包装仕様NO・プロテック条件に関わらずプロテックとして扱う(ボード種別・選定・配置・切断依頼書) |
| こちら側 | `force_protec` |
| VBA | **無い**(VER4.8.56 で足した) |
| 差 | **こちらだけにある** |

## 4. モードではないが、挙動が変わるもの

区別が要るので並べておきます。**これらは「モード」と呼びません。**

| | 何か | なぜモードでないか |
|---|---|---|
| 狭幅パレット | 選定がその経路を通ったかの**結果** | 人も受注も選べない。選定の答えとして決まる |
| カット前提 | ボード1枚ごとのタグ | 画面全体の挙動は変わらない |
| 候補変更(敷き詰め) | 選定の**別経路** | 押すたびにA→B→Cと回る。現行の選定・配置には触らない |
| サイズ指定(資材展開) | 製品サイズの**入口** | 下記 |

### サイズ指定について

「サイズ指定」という名前のモードはありません。製品サイズの入り方が
2通りあるだけです。

| 入口 | 何が起きるか |
|---|---|
| **資材展開**(ロット検索) | 製造板幅・板丈を製品サイズ欄に入れて資材選択へ移る |
| **手で打つ** | 製品サイズ欄に直接入れる |

**どちらも「セット」までは押しません**(VBA `Page1_OnBtnHBClick` と同じ)。
パレットに収まるかの検証(回転の要否を含む)は利用者が自分で行います。

プロテック・1P1185 の寸法の条件は**ロット(SIKALOT)の寸法**を見ます。製品サイズ欄に打った値ではありません。

## 5. 表で決まるモードの設定方法

### 足し方(どちらの表も同じ)

1. 設定 → **マスタ管理** を開く(管理者パスワードが要ります)
2. 左の一覧から「**プロテック条件**」または「**パレット限定条件(1P1185モード)**」を選ぶ
   - 表がまだ梱包資材マスタに無いときは、**取り込み(起動時・まとめて取り込み)のときに初期値入りで自動で作られます**。
     「+ 取り込み元に作る」を押しても作れます
3. 「**+ 行を足す**」を押し、欄を埋めて保存する
   - 見ない寸法は**空欄**のまま。ちょうどの値(例 12.0)は**最小と最大に同じ値**
   - 同じ包装仕様NOで条件を「または」にしたいときは、**行を分けて**足す
4. 直すときは行を押して直す。**止めるときは行を消さずに「有効」を 0 に**(最後の1行は消せません)

### 列の読み方

**1行の中の列は「かつ」、行と行は「または」。空欄の列は見ません。**
寸法の欄を書いたのに、ロットにその寸法が無い(0)ときは当たりません(確かめられないため)。

#### プロテック条件

| 列 | 意味 |
|---|---|
| 包装仕様NO(必須) | 受注の包装仕様NO(例 1P1255) |
| オーダー厚_最小 / 最大 | SIKALOT のｵｰﾀﾞｰ板厚の範囲 |
| オーダー幅_最小 / 最大 | SIKALOT のｵｰﾀﾞｰ板幅の範囲 |
| オーダー丈_最小 / 最大 | SIKALOT のｵｰﾀﾞｰ板丈の範囲 |
| 有効 / 並び順 / 備考 | 0 で止める / 並べる順 / メモ |

#### パレット限定条件(1P1185モード)

| 列 | 意味 |
|---|---|
| 包装仕様NO(必須) | 受注の包装仕様NO(例 1P1185) |
| 取引先名称 | 受注の取引先名称に**この文字を含む**なら(例 ﾅﾒｶﾜｱﾙﾐ) |
| 製造板幅_最小 / 最大・製造板丈_最小 / 最大 | SIKALOT の**製造**板幅・板丈の範囲(整数に切り捨てて比べる) |
| オーダー板厚_最小 / 最大・オーダー板幅_最小 / 最大・オーダー板丈_最小 / 最大 | SIKALOT の**ｵｰﾀﾞｰ**板厚・板幅・板丈の範囲 |
| 業界 | 発火したら、この業界のパレットだけ(空なら業界は見ない) |
| パレット幅・パレット丈(必須) | 発火したら、この寸法のパレットだけ(**決め打つサイズ**) |
| 有効 / 並び順 / 備考 | 0 で止める / 並べる順(小さい行から当てる) / メモ |

**製造で見る行はオーダーの欄を空に、オーダーで見る行は製造の欄を空に**します。両方書けば両方「かつ」です。

### 例: プロテックで、パレットも 1100×2500 に決め打つ

| 表 | 包装仕様NO | 条件 | 決め打ち |
|---|---|---|---|
| プロテック条件 | 1P1255 | オーダー厚 12〜12・オーダー幅 1075〜1081・オーダー丈 2332〜2338 | ― |
| パレット限定条件 | 1P1255 | オーダー板厚 12〜12・オーダー板幅 1075〜1081・オーダー板丈 2332〜2338(製造の欄は空) | パレット 1100×2500 |

→ このロットはプロテック(ボード)**かつ**パレットは 1100×2500 だけ。帯は
「【プロテックボードオーダー選択中】【1P1255モード 1100×2500 限定表示】」。

### いつ効くか

| どこで | いつから |
|---|---|
| 行を足した・直した端末 | **次にロットを開いたときから**(いま開いているロットは開き直す) |
| ほかの端末 | **取り込み(起動時の自動取り込み・まとめて取り込み)のあとから** |

### 表が無い・読めないとき

起動時に手元の表が空なら**初期値**を入れます(上の各モードの「初期値」の行)。梱包資材マスタに表が無いあいだも、
手元の初期値で前と同じに動きます。直した値を起動のたびに書き戻すことはありません。

## 突き合わせの結論

**判定条件はすべて一致していました。** 移植漏れ・条件違いはありません。

そのうえで、現場の依頼で次を変えています(VBA には無い)。

| 版 | 何を変えたか |
|---|---|
| VER4.8.56 | プロテックの条件を表(プロテック条件)にし、ｵｰﾀﾞｰ寸法の条件と「プロテック 強制」を足した |
| VER4.8.58 | 1P1185 の条件と決め打つパレットを表(パレット限定条件)にした |
| VER4.8.59 | プロテックの許容を全部 上下共用 -10mm にした(それまでは 1P1216 だけ -10mm、ほかは -80mm)。表が無ければ取り込みで作る |
| VER4.8.60 | パレット限定条件に ｵｰﾀﾞｰ板厚・板幅・板丈 の列を足した(製造とオーダーを分ける) |

VBA と思想が違うのは次の2点で、どちらも意図的です。

1. **上下共用の画面上の扱い** ── プロテックも上下共用の一種として
   上用キャンバスを隠します(製品幅を大きく超えるボードを超過禁止の枠へ
   配置しようとして静かに失敗する不具合があったため)。選定側の分岐は
   VBAと同じく別のままです
2. **プロテックの `cond1`(納入先)** ── VBA側で廃止済みの条件なので
   移植していません
