# BoardMaster に拠点を足す

拠点は、疲労度の距離を測る**原点**です。既定の **L-1 / HVC / LVC** は足さなくてもいつも使えます。
それ以外の場所(例: 大板)を拠点にしたいときに、この手順で足します。

> 拠点と「作業ライン」(予定ロットの L-1 / LVC / HVC / 機側 …)は別のものです。
> 作業ラインはアクセス権限の「権限」の列に書きます。拠点を足しても作業ラインは増えません。

---

## どこに入るか

**梱包資材マスタ(共有) の BoardMaster** に、拠点だけの行を1行足します。

| 列 | 入れる値 | メモ |
|---|---|---|
| ボード幅 | **0** | 0 にしておくとボードの候補に出ない |
| ボード丈 | **0** | 同上 |
| ボードタイプ | **拠点** | ボード種別・使用実績にも出ない |
| データラベル | **拠点** + 名前(例 **拠点大板**) | 「拠点」で始めるのが目印 |

---

## やり方A: 棚検索の「拠点を追加」(かんたん。VER4.8.85〜)

上の表の行を**ツールが自動で足します**。

1. 設定画面の「パスワード」タブ「マスタ編集の認証」で管理者パスワードを通す
   (この端末に **資材モード(mode:material)** の権限が要ります。マスタ管理と同じ)
2. **棚検索** → 「**配置編集**」を押す(編集中になる)
3. 下に出る「**拠点を追加**」の欄に名前(例 `大板`)を入れて「**追加**」
   - `拠点大板` と打っても `大板` として足します
4. 図の**中央**に赤い拠点の札が出るので、持ち場の位置へドラッグ
5. 「**配置編集**」をもう一度押して終える → 保存。ここから距離・疲労度が測れる

断られたとき:
- 「資材モードを持つ端末だけです」→ アクセス権限にこの端末の `mode:material` の行が要る
- 「管理者パスワードを入れないと直せません」→ 手順1をやってから押し直す
- 「既定の拠点です」→ L-1 / HVC / LVC は足さなくてよい
- 「もう図にあります」→ 同じ名前の拠点が図にある

## やり方B: マスタ管理で手で足す(VER4.8.63〜)

1. 設定画面 → マスタ管理 → **BoardMaster** → 「1行足す」
2. 上の表のとおりに入れる(ボード幅 0 / ボード丈 0 / ボードタイプ 拠点 / データラベル 拠点大板)
3. 棚検索 → 「配置編集」を押すと、図の**左上**に赤い拠点の札が出る → 位置へ動かす
4. 「配置編集」を終える → 保存

---

## ほかの端末では

- 選択肢(設定の「動作」・棚検索の「拠点」)には、**次の取り込みで**出ます(マスタは共有なので)
- **図の上の位置は端末ごと**です(配置図は各端末の `data\floor_plan.json`)。
  ほかの端末で「配置編集」に入ると左上に札が出るので、そこで置くか、
  置いた端末の配置図を**配布設定**で配ります

## 決まり(忘れやすいところ)

- **図に置くまでは距離を測れません**(選ぶことはできる。疲労度優先は通常選定で選ぶ)
- 名前の全角半角・ハイフン・空白・大文字小文字の違いは同じ拠点として扱います(`拠点L1` も `拠点L-1` も既定の **L-1**)
- 名前に「,」は使えません(データラベルの区切りなので)。1行に `拠点A,拠点B` と並べて複数足すことはできます
- 拠点の印(`拠点〇〇`)は置き場として数えません

## 消すとき

- マスタ管理で BoardMaster のその行を消すと、**まだ図に置いていない端末**の選択肢からは(取り込みのあと)消えます
- **図に置いた端末では残ります**(選択肢は「図の拠点 + マスタの拠点」なので)。図から消すには、その端末の棚検索の配置編集で
  「**出荷時に戻す**」(配置図ぜんぶが出荷時に戻るので注意)
