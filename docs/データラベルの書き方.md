# データラベルの書き方

マスタ管理で **BoardMaster**(ボード)と **CornerboardMaster**(アングル)の「**データラベル**」列に書くもの。
この列が「その資材が棚のどこにあるか」と「拠点」を決めます。棚検索・疲労度(距離)・置き場の資材一覧は、すべてこの列を見ます。

---

## 1. 書けるもの

| 書くもの | 例 | 意味 |
|---|---|---|
| 置き場の名前 | `lblItem34` | その資材が置いてある棚。棚検索の図の **34** の箱 |
| 拠点 | `拠点大板` | 距離を測る原点(持ち場)を足す。「拠点」の後ろが拠点の名前 |

- **カンマ(`,`)で区切って複数**書けます。例 `lblItem1,lblItem8`
- 前後の空白は無視します

---

## 2. 置き場(lblItem〇〇)

```
lblItem34
lblItem1,lblItem8
```

- 棚検索の図の箱は、**番号だけ**が出ます(`lblItem34` → **34**)。マウスを載せると元の名前が出ます
- **同じ資材を複数の置き場に置いているとき**は、全部書きます。拠点から**いちばん近い置き場**で距離を測ります
- 1つの置き場に、サイズ違いのボードやアングルを置いてよい(棚検索で置き場を押すと、置いてある資材が全部出ます)
- 図に無い名前を書くと、棚検索の「**マスタが指しているのに図に無いラベル**」に出ます。棚検索の「配置編集」で箱を足すか、名前を直してください
- 空欄なら「置き場が分からない資材」です。疲労度の距離は既定の **25点**(真ん中くらい)で数えます

---

## 3. 拠点(拠点〇〇)

拠点は、疲労度の距離を測る**原点**です(L-1 / HVC / LVC など)。設定画面の「動作」で選び、資材選択と棚検索で同じ拠点を使います。

### 拠点を足す(例: 大板)

手順の控えは **[BoardMasterに拠点を足す.md](BoardMasterに拠点を足す.md)** にまとめてあります(棚検索の「拠点を追加」でも足せます)。

マスタ管理で **BoardMaster** に1行足します。

| 列 | 入れる値 |
|---|---|
| ボード幅 | **0** |
| ボード丈 | **0** |
| ボードタイプ | **拠点** |
| データラベル | **拠点大板** |

1. 取り込むと、棚検索と設定画面の「拠点」の選択肢に **大板** が出ます
2. 棚検索の「**配置編集**」を押すと、図の左上に**赤い拠点の札**「大板」が出ます。持ち場の位置へ動かします
3. 「配置編集」をもう一度押して終えると保存されます。ここから距離・疲労度が測れます

### 決まり

- **図に置くまでは距離を測れません。** 選ぶことはできますが、棚検索は「まだ図に置いていない」と言い、資材選択の疲労度優先は通常選定で選びます
- **1行に複数書けます。** 例 `拠点L-1,拠点LVC,拠点HVC`
- **今ある拠点を書いても増えません。** 全角半角・ハイフン・空白・大文字小文字の違いは同じ拠点として扱い、図の名前を使います(`拠点L1` も `拠点L-1` も図の **L-1**)
- **拠点の行はボードではありません。** ボード幅・丈が 0 の行と、ボードタイプが「拠点」の行は、ボードの候補・ボード種別・ボード使用実績に出ません
- 拠点の印(`拠点〇〇`)は置き場として数えません(「図に無いラベル」にも出ません)
- ボードの行に `lblItem1,拠点大板` のように混ぜて書いても拠点は足されますが、**拠点は専用の行に書く**ほうが分かりやすいです
- 拠点は **BoardMaster** に書きます(CornerboardMaster には書きません)

### 拠点を消す・名前を変える

- マスタの行を消しても、**図に置いた拠点の札は残ります**(図の座標は棚検索の配置図が持っているため)。
  いまは**拠点の札だけを図から消す操作はありません**。配置編集の「出荷時に戻す」は図の編集を**全部**捨てる(動かした置き場も戻る)ので注意してください
- 名前を変えると別の拠点になります。設定画面で選び直してください

---

## 4. どこで使われるか

| 画面・計算 | 使い方 |
|---|---|
| 棚検索(最寄り置き場の検索) | 寸法から資材を探し、拠点からいちばん近い置き場を光らせる |
| 棚検索(置き場をまとめて見る) | 資材選択で選んだ資材の置き場を全部光らせ、合計疲労度を出す(選定と同じボード種別の置き場で測る) |
| 棚検索(置き場を押す) | その置き場に置いてある資材の一覧 |
| 資材選択の疲労度優先 | 拠点から置き場までの距離を点にする(`docs/疲労度の計算.md`) |
| 在庫考慮(置き場ごとの在庫) | 看板の1行は、その資材が**その看板の置き場に置いてあるとき**だけ効く。置き場はこの列で決まる(下の「5」) |
| 棚検索の図の色 | 置き場の色(ボード / IK / プロテック / アングル)はボードタイプとアングルから決まる |

## 5. 看板置き場(どの看板がどの置き場の看板か)

マスタ管理の「**看板置き場**」は、看板の表(看板_L1 など)がどの置き場の看板かを決める表です(VER4.8.68〜)。
置き場の欄は、データラベルと同じ書き方(`lblItem1,lblItem2`)です。

| 列 | 書くもの | 例 |
|---|---|---|
| 看板 | 看板の表の名前 | `看板_L1` |
| 資材の注記 | 資材名の後ろの(…)の中身。空なら(…)の無い行 | `大板棚`(資材 `ハードボード(大板棚)` の行) |
| 置き場 | その看板の置き場 | `lblItem14,lblItem15` |
| 幅・丈 | このサイズの看板だけ(向きは問わない)。空ならどのサイズも | `1000`・`1600` |

- 看板の行は、その資材が**この表の置き場に置いてあるとき**(データラベル)だけ、その置き場の在庫を言います。
  板のデータラベルに書いていない置き場の看板は、その板には効きません
- 1つのサイズだけ別の棚にあるときは、幅・丈を書いた行を足します(例: 看板_LVC・幅1000・丈1600・lblItem23)。
  棚ごと足すと、その看板の別サイズの行までその棚を言うようになります
- 置き場を足した・移したときは、データラベルとこの表の両方を直してください
- 止めたい行は「有効」を 0 にします(最後の1行は消せません)
- 考え方は `docs/疲労度の計算.md` の「8」

## 6. プログラムの場所

| 何 | 場所 |
|---|---|
| データラベルの読み分け(置き場 / 拠点) | `packaging_tool/location_service.py` の `_split_labels`・`master_base_points`・`base_key` |
| 拠点の選択肢 | `location_service.base_point_names` |
| 配置編集で図に出す | `packaging_tool/layout_session.py` の `_show_unplaced_bases` |
| 拠点の行をボードから除く | `packaging_tool/board_selection_service.py` の `BOARD_ROWS_ONLY` |
| マスタ管理の欄の案内 | `packaging_tool/master_columns.py` の `COLUMN_NOTE` |
| 看板置き場 | `packaging_tool/kanban_shelves.py`(在庫の判定は `material_service.build_board_stock_map`) |
