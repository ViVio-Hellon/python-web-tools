# 梱包資材総合ツール(Python版) 起動手順と使い方

VBA版と同じ操作感で使えるようにしてありますが、起動の仕方だけは違います。
このページだけ読めば動かせるようにまとめました。

---

## 1. 用意するもの

必要なのは **Python 本体**と、追加パッケージ2つだけです。Excelは要りません。

| 必要なもの | 確認方法 | 備考 |
|---|---|---|
| Python 3.9以降 | `python --version` | 3.11 / 3.12 で動作確認済み |
| Flask と waitress | `pip install -r requirements.txt` | 初回に1度だけ |
| ブラウザ | Edge | 画面はブラウザで開きます |
| 取り込み元の sqlite3 | 設定画面で確認 | 共有フォルダに置かれたファイル(第3章) |

Pythonが入っていない場合は <https://www.python.org/downloads/> から
インストールしてください。**インストーラの最初の画面で
「Add python.exe to PATH」に必ずチェック**を入れてください。
ここを入れ忘れると、あとで `python` コマンドが見つからなくなります。

---

## 2. 起動する

### いちばん簡単な方法(Windows) — デスクトップ版 (VER4.0.0〜)

フォルダの中の **`梱包資材総合ツール.exe` をダブルクリック**するだけです。
専用の窓が開いてアプリが立ち上がります。**押すファイルはこれ1つです。**

- **ポートを使いません。** ブラウザ版で起きていた「応答が返りません」
  (プロキシ・セキュリティ製品・ポートの取り合い)が起きません
- Python は今までどおり各PCに入っているものを使います(必要なのは Flask だけ)
- もう一度ダブルクリックしても2つ目は開かず、開いている窓が前に出ます
- 窓の **×** か画面右上の **「終了」** で終わります。保存していない配置図や
  取り込みの途中があるときは、終わる前に訊きます
- 帳票(Lot印刷・切断依頼・配置図印刷)は別の窓で開きます。上の帯の
  **「印刷する」** で印刷、**「閉じる」** でその窓だけ閉じます
- 起動できないときは、窓に**理由・次にすること・ログの場所**が出ます
  (「Python が見つかりません」なら、下の「うまくいかないとき」へ)

作りの説明は [デスクトップ版.md](デスクトップ版.md) にあります。

### ブラウザ版(予備)

exe が無いとき・動かないときは、**`Start.vbs` をダブルクリック**します。
ブラウザが開いてアプリが立ち上がります(以前からの起動方法)。
**デスクトップ版とブラウザ版を同時に開かないでください**(同じ手元のDBを2つが触ります)。

現場モードで開くか資材モードで開くかは、**この端末に許されたモード**で
決まります。発注の確認・取り消しを行う端末は、同じ `Start.vbs` を押せば
そのまま資材モードで開きます ── どちらで開くかを覚えておく必要はありません。

**モードは画面右上でも切り替えられます。** ただし切り替えられるのは
**あなたに権限のあるモードだけ**で、権限が無ければ選択肢に出ません。
権限は `アクセス権限` マスタで、Windows のログインIDやPC名ごとに
決まっています(第3章)。いま何が使えるかは設定画面の
**「この端末の権限」** で確かめられます。

起動しないときは **`start.bat`** を使うと、理由が画面に出ます。

### 起動中に出る画面 (VER2.5.0〜)

ブラウザが開いた瞬間に、濃い青地の**起動待機画面**が出ます。
アプリ名と版・いま何をしているか・4つの段(実行環境 / 準備 / 取り込み /
完了)が出て、準備ができると自動で業務画面へ切り替わります。

- **取り込みを待たずに使い始められます。** 右下の
  「待たずに使い始める ▸」を押すと、取り込みは背景で続きます
  (進み具合は画面上の帯に出ます)
- 起動できなかったときは、この画面に**理由とログの場所**が出ます

### 終わり方 (VER2.5.0〜)

**タブを閉じれば終わります。** 10秒ほどで Python 側も終了します。
以前は Python が残ってしまい、次に起動したときに古いほうが開いて
**入れ替えた新しい版が動かない**ことがありました。

| やり方 | いつ使うか |
|---|---|
| **タブを閉じる** | ふだんはこれで十分です |
| 画面右上の **「終了」** | すぐ確実に終わらせたいとき |
| **`stop.bat`** | 画面が出ていないとき・まとめて止めたいとき |

- **取り込みの途中では終わりません。** 終わるまで待ってから終了します
  (中途半端なデータを残さないため)
- 画面を**再読込しても終わりません**。閉じたのか読み直したのかを
  見分けています
- しばらく放置しただけでも(90秒以上、画面が閉じられている状態)終わります
- **送る・登録する前に打っていた文字は残ります**(VER4.7.2〜)。倉庫へのコメント・発注の欄・
  在庫の受け入れ・マスタ管理の1行は、途中でツールが止まっても(ランチャーの［ツール停止］・
  ブラウザが落ちた など)、次にその欄を開いたときに戻り、「前に打ちかけていた内容を戻しました」と
  出ます。**まだ送っていない**ので、確かめてから送ってください

> **「どの版が入っていますか」と聞かれたら**、画面の**左上**を読んでください。
> アプリ名の右に `VER1.0.0` のようなバッジが常に出ています。どの画面を
> 開いていても消えません。

### うまくいかないとき

デスクトップ版は、窓に理由が出ます。ブラウザ版は **`start.bat`** を実行すると、理由がコンソールに出ます。

| 症状 | 原因と対処 |
|---|---|
| (デスクトップ版)「Python が見つかりません」 | Python を入れ、インストーラの最初の画面で「Add python.exe to PATH」にチェック。そのあと `python -m pip install -r requirements.txt` |
| (デスクトップ版)ダブルクリックしても窓が出ない | exe だけをコピーしていないか確認してください。アプリ一式のフォルダの直下に置きます(ショートカットは可)。WebView2 ランタイムが入っていない古いPCでは開きません(Windows 10/11 は通常入っています) |
| `'python' は認識されていません` | PythonにPATHが通っていません。入れ直して「Add python.exe to PATH」にチェック |
| 「必要なパッケージが入っていません」 | 表示されたコマンド(`pip install -r requirements.txt`)を実行してください |
| ダブルクリックしても何も起きない | `Start.vbs` だけをコピーしていないか確認してください。アプリ一式のフォルダの中から実行します(ショートカットは可) |
| ブラウザは開くが「応答が返りません」 | プロキシ設定に `127.0.0.1` の除外が無い場合が典型です(ブラウザ側の除外も確認) |
| 画面は出るが一覧が空 | データの取り込みがまだです。次の章へ |

## 3. データの取り込み

このツールは手元のSQLite(`data/packaging_tool.db` の1ファイル)で動きますが、
**共有フォルダの取り込み元ファイルとやり取りします**。

```
共有の.sqlite3  →  手元のSQLite   取り込み(マスタ・仕掛台帳)
手元のSQLite    →  共有の.sqlite3  書き戻し(倉庫発注・入出庫履歴)
```

### 誰がどのモードを使えるか(アクセス権限)

**取り込み元に `アクセス権限` という表を置くと、端末ごと・人ごとに
使えるモードを決められます。** 他のマスタと同じく取り込んで使うので、
**共有フォルダの1か所を直せば全端末に効きます**。

1行が1つの許可です。

| ログインID | PC名 | 権限 | 有効 | 意味 |
|---|---|---|---|---|
| yamada | (空) | `mode:material` | 1 | 山田さんはどのPCでも資材モード |
| (空) | NLM-PC-042 | `mode:material` | 1 | この端末なら誰でも資材モード |
| suzuki | NLM-PC-042 | `mode:material` | 1 | 鈴木さんがこの端末のときだけ |

- **空欄は「問わない」**という意味です。ログインIDとPC名の**両方を空に
  した行は効きません**(全員への許可になってしまうため)
- 権限は `mode:field`(現場)と `mode:material`(資材)の2つ。
  両方使う人には**2行**書きます
- 大文字小文字は区別しません。`有効` を `0` にすると止められます
- **登録が無い端末は現場モードだけ**になります。締め出さないためです
- **この表はほかのツールと共用しています。** 本ツールが読むのは `mode:field` と
  `mode:material` だけで、それ以外の値(ほかのツールの権限)は読み飛ばします。警告にもしません
  (設定画面に「ほかのツールの権限 ◯種類を読み飛ばしています」と参考で出ます)。
  1つの欄に「,」で区切って複数書かれていても、本ツールのコードだけを拾います
- 本ツールのコードに**よく似た**値(`mode:materia` など)は、書き間違いとして設定画面で教えます

うまく効かないときは設定画面の **「この端末の権限」** を見てください。
いまのログインIDとPC名、効いた行、効かない行(綴り違いなど)が出ます。

### 置き場所を決める(最初に1回だけ)

**.sqlite3 は共有フォルダに1つ置いて、全ラインの端末がそれを見ます。**

設定画面の「取り込み元」で、2つのフォルダを指定して「置き場所を保存」を
押してください。端末ごとに1回設定すれば覚えます。

| 設定 | 何を指定するか |
|---|---|
| 梱包資材マスタ | `梱包資材マスタ.sqlite3` を置いた共有フォルダ |
| 仕掛台帳 | `SIKALOT/SIKAHIKI/SIKAODR.sqlite3` のあるフォルダ(既定は `\\nlmsrvngy03\Read\【New】仕掛\台帳`) |
| 仕掛台帳(2つ目) | 1つ目で見つからないときに見るフォルダ(VER4.4.0〜)。空なら使いません。下の説明 |
| 包装仕様書の図面URL | 包装仕様書の図面を返すアドレス(下記)。空なら図面は出ません |

ファイル名を変えている場合も、そのフォルダにある `.sqlite3` を自動で探します。

**仕掛台帳の2つ目の置き場所**(VER4.4.0〜)を入れておくと、1つ目で見つからないときに2つ目を見ます。

- **1つ目にファイルが無い** … そのファイル(SIKALOT / SIKAHIKI / SIKAODR ごと)は2つ目から読みます。
  1つ目のファイルが壊れていて読めないときも同じです
- **1つ目にファイルはあるが、目当てのロット(受注)が入っていない** … 取り込みのあとに、2つ目にだけある
  ロット・引当・受注を足します。**同じロット・受注が両方にあれば1つ目を使います**
- **1つ目にロットはあるが、BOX最終実績の板厚・板幅・板丈が空**(BOX実績寸法のロット)… ロット情報の画面で、
  「BOX実績寸法」の見出しの横に**選ぶ欄**が出ます(VER4.7.4〜)。2つ目の SIKALOT の同じロットの行が
  BOX設計_設備名 で工程の順(BOX番号の順)に並ぶので、選ぶとその行の **BOX設計_板厚・板幅・板丈** を使います
  (表示・帯・資材展開。VER4.7.5〜。それまでは BOX最終実績を見ていました)。
  選んだものはそのロットについて覚えます。「選んでください」に戻すと1つ目の値に戻ります
- **1つ目にロットはあるが、BOX最終実績_設備名が HOT**(BOX実績寸法のロット。VER4.7.7〜)… 寸法が入っていても
  **HOT の値は使わず**、上と同じ選ぶ欄を出します(HOT の BOX最終実績寸法は使うに値しない、と現場)。
  選ぶまでは板厚・板幅・板丈を空(0)にするので、資材展開は押せません。寸法の説明に
  「BOX最終実績_設備名が HOT のため、その寸法は使いません」と出ます
  - 例: H9022S0 → 「PSW(100.000 × 1200.0 × 2850.0・BOX2)」「KEN(100.000 × 544.0 × 544.0・BOX4)」
  - 2つ目にも値が無いときは、寸法の説明に「2つ目の仕掛台帳にもありません」と出ます
  - 2つ目の SIKALOT は1つ目と列が違います(44列。BOX実績_板厚・板幅・板丈 などが無い)。2つ目の行はその行に
    ある列で読みます。板丈が 0 の行(例: N7154X0 = 4.52 × 127.8 × 0)は**コイル形状**です。0 のまま出します
    (板丈が 0 だと資材展開は押せません)
- 1つ目を丸ごと捨てて2つ目へ移ることはしません。**ファイルごと・ロットごと**に2つ目を見ます
  (例: SIKALOT が無い → SIKALOT だけ2つ目、SIKAHIKI はある → 1つ目を使い、その中に無いロットだけ2つ目)
- 起動時の取り込みは、1つ目と2つ目のどちらかのファイルが新しくなっていれば読み直します
- 変えるときは、1つ目と同じく管理者パスワードが要ります。設定画面「いまの状態」の「仕掛台帳」に、
  探す順(1つ目 → 2つ目 → マスタのフォルダ)と2つ目にあるファイルの数が出ます

#### 包装仕様書の図面URLの調べ方

ロット検索の画面に**包装仕様書の図面をそのまま出す**ための設定です。
設定すると、ロットを引いた時点で裏で図面を取ってきて、画面の下に出ます
(閲覧システムを開いて仕様NOを打ち直す必要がなくなります)。

アドレスはツール側からは分からないので、一度だけ調べて登録してください。

1. ブラウザで包装仕様書の閲覧システムを開く
2. **F12**(開発者ツール)を押して **「ネットワーク」** タブを開く
3. 包装仕様NOを入れて **「検索」** を押す
4. 出てきた一覧のうち、**種類が `png` / `jpeg` / `gif` のもの**を選ぶ
5. その **URL** をコピーし、包装仕様NOの部分を `{no}` に置き換えて貼り付ける

例(実際のアドレスは環境によって違います):

```
http://nlmfangysysv:9084/NgyPkgWeb/rest/pkgSpec/image?pkgSpecNo={no}
```

> `{no}` を入れ忘れると保存のときに教えます。画面のアドレス
> (`#!/home?mode=...` のほう)を入れると、図面ではなくHTMLが返るので
> 「図面ではなく text/html が返りました」と出ます。

> **手元のDB(`data/packaging_tool.db`)は端末ごと**に作られます。
> このファイルを共有フォルダに置かないでください。SQLiteはネットワーク越しの
> ファイル共有だとファイルロックが正しく効かず、複数台から同時に使うと
> データが壊れることがあるためです。**共有して見るべきデータは取り込み元が正**で、
> こちらで登録した発注・入出庫は取り込み元へ書き戻されるので、
> 他のラインからも同じデータが見えます。

### 取り込み方

**起動すると自動で取り込みます。** 何もする必要はありません。

- 前回から**更新されたファイルだけ**を読むので、毎回待たされることはありません
  (仕掛台帳は日々更新されるので実質毎回、マスタは変わったときだけ)
- 取り込みは裏で走るので、**画面はすぐ使えます**
- いま何%まで進んだか・どのテーブルを読んでいるかは、
  **設定画面の進捗バー**に出ます(VBA版の進捗画面と同じ)。
  取り込み中は取り込みボタンが押せなくなります(二重に走らせないため)
- 結果は設定画面の「最近の結果」に残ります
- 取り込みのあと、**パレットの適合範囲を基準表から計算し直します**
  (VBAの `RunUpdatePalletAll` に当たる処理)。上限はパレットの現物サイズで
  頭打ちにするので、「自分より大きい製品を受けられる」と名乗る行が
  できません。手で流したいときは設定画面の
  **「適合範囲を再計算」** を押してください

すぐに最新にしたいときは設定画面の **「まとめて取り込み」**、
仕掛台帳だけでよければ **「仕掛台帳だけ」** を押してください。
自動取り込みを止めたいときは、同じ画面のチェックを外して保存します。

### 置き場所の書き方(絶対 / 相対)

設定画面の「取り込み元」で、2通りの書き方が使えます。

| 書き方 | 例 | どこを見るか |
|---|---|---|
| **絶対** | `\\nlmfangyshrd\各課共有\…` / `C:\data\src` | 書いたとおり |
| **相対** | `data\src` / `..\共有\台帳` / `src` | **アプリのフォルダ**から |

相対は「いまの作業フォルダ」ではなく**アプリのフォルダ**から数えます。
起動の仕方で行き先が変わらないので、フォルダごとコピーして配っても、
写しの中の同じ場所を指し続けます。相対で書くと、入力欄の下に
**実際に見に行く先**が出るので、思い違いに気づけます。

「**参照…**」を押すと、このPCから見えるフォルダを一覧できます
(ブラウザのファイル選択では、このPCのフォルダは選べません)。
**ファイルを押しても選べます** ── そのファイルの入れ物が入り、
押したファイルに印が付きます。空にすると既定の共有フォルダに戻ります。

### マスタが「開けませんでした」と出るとき

「いまの状態」に、**開いてみて分かったこと**がそのまま出ます
── 大きさ・sqlite3 の印があるか・`-wal` などが残っているか・
どの開き方を試して何と言われたか。よくあるのは次の3つです。

| 出かた | 原因 | すること |
|---|---|---|
| 先頭が sqlite3 の印ではありません | 名前だけ変えた別形式(Access 等)/ 変換が途中で止まった | 変換をやり直して置き直す |
| WAL のまま置かれています | 共有フォルダの上では WAL のファイルは開けません | 変換したPCで `PRAGMA journal_mode=DELETE;` を実行してから置き直す |
| (それ以外) | 他のアプリが掴んでいる / 読み取り権限が無い | 変換ツールや Access を閉じる。共有の権限を確かめる |

**「開き方: 手元への写し」と出たときは、動いてはいますが遅くなって
います。** 共有の上では開けないので、読むたびに手元へ写しています。
たいていは WAL が原因なので、上の表のとおり置き直すと写さずに読めます。

### 取り込み元を読むのに必要なもの

**何も要りません。** 取り込み元は `.sqlite3` なので、Pythonに最初から
入っている機能だけで読み書きできます。ドライバの追加インストールは不要で、
端末によって動いたり動かなかったりすることもありません。

いま何が見えているかは設定画面の **「いまの状態」** に出ます
(どのファイルが見つかったか・読めるか・書き戻せるか)。
コマンドプロンプトから確かめたいときは:

```bat
python scripts\import_source.py --check
```

### 取り込み元への書き戻し

**倉庫送信**と**在庫の受入・払出**をすると、その内容は手元のDBに保存された
あと、**自動で取り込み元にも送られます**。他部署が同じファイルを見ていても
同じデータが見えます。

うまく送れなかったぶん(共有フォルダに繋がらなかった、他の端末が書いていた
等)は**次に送るときにまとめて反映**されます。同じ行が二重に登録されることは
ありません。手動で送りたいときは設定画面の
**「取り込み元へ反映」**を押してください。

> **VER2.2.1 より前をお使いだった場合。** 取り込みのたびに発注と
> 入出庫履歴が倍になる不具合がありました。原因は直っていますが、
> **すでに増えた行は残ります。** 片付けは順番が大事です ──
> ①全端末を入れ替える ②各端末で1回ずつ取り込む(手元に残っていた分が
> ここで最後に送られます) ③数える ④消す ⑤もう一度取り込む。
> 詳しくは `docs/変更履歴.md` の VER2.2.1 を見てください。
>
> ```bat
> python scripts\dedupe_writeback.py        :: 数えるだけ
> python scripts\dedupe_writeback.py --fix  :: 消す(控えを取ってから)
> ```

#### 重複を消す(設定画面の「--fix を実行」。VER4.8.4〜)

設定画面の「いまの状態」に **「重複 ○○ に N件」** と出たら、同じ1件が2回以上入っています
(人が2回書いたものではありません)。カードのボタンを押すと「取り込みと反映」の面へ移ります。
そこの **「--fix を実行(重複を消す)」** を押すと、確認の窓で次の4つを言ってから実行します。

1. 共有の梱包資材マスタを、同じフォルダへ `梱包資材マスタ.bak-日時.sqlite3` として丸ごと控えに写す
2. 共有の重複を消す(いちばん先に入った行を残す)
3. この端末へ取り込み直す
4. この端末に残った重複も消す(共有に表が無いもの、たとえば発注コメント閲覧も)

- **管理者認証**(「パスワード」の面)と、**この端末に資材モードの権限**(アクセス権限)が要ります。足りなければ、何が足りないかを出して断ります
- 「重複」とは、取り込みと同じ形にそろえてから(日付の書き方・`140.000` と `140.0`・空欄など)、管理番号・送信ID などの番号を除いた
  **全部の列が同じ行**です。**値が1つでも違う行は消しません**(丈 2502.5 と 2502 など)
- ほかの端末は次の取り込み(起動時・倉庫連携の見張り・設定の取り込み)で直ります
- 画面を開けないとき・重なった行の中身を見たいときは `python scripts\dedupe_writeback.py --show`(同じ決め方で数えます)

VER4.7.8 で、重なりが**できる原因**(取り込みの直後に裏の送信が割り込むと、表をまるごと送り直していた)も直しています。

> 書き戻すのは**このツールで新しく作ったデータだけ**です。
> パレットやボードのマスタは、取り込みや書き戻しでは書き換えません
> (直したいときは次の「マスタを確認する・直す」から)。

### マスタを確認する・直す

設定画面の **「マスタ管理」** で、梱包資材マスタの中身を見られます。
左に表、右にその中身が出ます。行を押すと1行ぶんが縦に並ぶので、
列の多い表もそのまま読めます。上の欄に打って「絞り込む」を押すと、
**どの列に入っていても**当たります(例: `1100` / `A-1` / `ハードボード`)。
**列名(見出し)を押すと、その列で並び替えます。** もう一度押すと逆順です
(▲小さい順 / ▼大きい順。まだ並べていない列には薄い ⇅ が出ます)。
数字は数の大きさで並びます(`999` → `1000`)。空の行はいちばん後ろです。
画面に出ていない行も含めた**全件**で並び替えます。

直せるのは次の6つです。ほかの表は見るだけで、**なぜ直せないのかも
その場に出ます**。

| 表 | 中身 |
|---|---|
| パレット | 寸法・適合範囲・記号・保管位置・在庫数 |
| ボード | ボードの幅丈と種別 |
| アングル | アングルの丈 |
| 梱包保護材 | 板厚・板幅・板丈の範囲と、使う保護材 |
| 松板・角材 | 品名・厚・幅・丈の範囲と発注コード |
| アクセス権限 | 誰がどのモードを使えるか |

**直すのは共有フォルダの元ファイルです。** 手元の写しは取り込みの
たびに入れ替わるので、写しを直しても次の取り込みで消えます。
元を直したあとはその表だけをその場で読み直すので、**直した結果は
すぐこの端末に効きます**。他の端末には、次の取り込みで届きます。

- 「取り込み元へ書く」を押すまでは何も変わりません
- 消すときは、もう一度「消す」を押して確かめます(戻せません)
- 更新日時・登録日時は空欄でよく、保存したときの日時が入ります

#### 列を足す(VER4.2.0〜)

直せる表(上の表と、「表を持ってくる」で足した表 ── 例: `班員名簿`)には、
**「+ 列を足す…」** で列を足せます。管理者認証が要ります。

1. 表を選んで「+ 列を足す…」を押す
2. **列の名前**・**型**(文字 / 整数 / 小数)・**最初の値**を入れる
   (最初の値は、いまある行すべてに入ります。空なら空のまま)
3. 「取り込み元に列を足す」→ 確認で「OK」

足した列はすぐ一覧に出て、ほかの列と同じように行を開いて直せます。
ほかの端末のマスタ管理にも出ます(共有の元ファイルに足すため)。

- **列は消せません。** 名前と型を確かめてから足してください
- 同じ名前の列(英字の大文字・小文字の違いだけのものも)、`[` `]` `"` `.` などの記号を
  含む名前、41文字以上の名前は断ります
- パレット・ボードなど資材課の表に足した列は、**マスタ管理で見る・直すだけ**です。
  選定や配置の計算・帳票には使われません(使うにはプログラムを直します)
- 「表を持ってくる」で **Access の最新に入れ替えると、足した列は残りますが値は空に
  なります**(Access に無い列なので)。値の入っている列があれば、入れ替える前の
  確認に「⚠ マスタ管理で足した列の値が空になります(班員名簿(電話番号 3行))」と
  出ます。パレットの在庫の行(位置のある行)は入れ替えでも残すので、その行の値も残ります
- **資材パレット注文管理(倉庫への発注)は入れ替えません**(ツールから送った発注や確認・取消の印が
  消えるため)。代わりに「**無い行だけ足す**」を選べます。Access にしか無い発注
  (登録日時・LotNo・発注コード・厚・幅・丈 が全部同じ行が梱包資材マスタに無いもの)だけを足し、
  今ある行は消しも書き換えもしません。何度押しても同じ発注を二重に足しません

**直せるのは資材モードを持つ端末だけです。** 現場モードでは見るだけに
なり、「直すには何をどこに足せばよいか」が画面に出ます
(第2章「モード」)。まだ誰も `アクセス権限` に登録されていないあいだは
直せます ── そうしないと最初の1行を入れられないためです。

> 登録を1行入れると、その時点で関門が閉まります。**条件(ログインID /
> PC名)を書き忘れた行**はどの端末にも効かないので、それだけを入れると
> 全員が現場モードに落ち、画面から直せなくなります。そうなったときは
> 共有フォルダの `梱包資材マスタ.sqlite3` を直接開いて直してください。
> 書き忘れた行は「いまの状態」の面が警告に出します。

### 複数の端末で同時に使うとき

ラインごとの端末が**同じ取り込み元ファイルを同時に触る**前提で作ってあります。

- **同じ行が二重に入ることはありません。** 送る前にその行を
  「送信中」として予約するので、続けて操作して裏の処理が重なっても、
  同じ行を2度は送りません
- **他の端末が書いている最中に当たったら、少し待って再試行**します
  (1秒 → 2秒 → 3秒 の3回まで)。それでも駄目なら次の機会に回します
- 送信の途中で端末が落ちて予約だけ残った場合は、**10分たつと拾い直します**。
  このときだけ二重で入る可能性があるので、ログに警告が出ます
- 同じパレットの在庫を2台で同時に更新した場合は、**あとから更新した側に
  「他の端末が同時に更新しました」と出ます**。画面を更新してやり直してください
  (先に更新した内容が消えないようにするためです)

> **手元のDBは端末ごと**なので、そちらで競合することはありません。
> 共有されるのは取り込み元のファイルだけです。

## 4. 画面の構成

**左の列**で7つの画面を切り替えます。上から**作業する順**に並んでいます。

| 画面 | 何をする画面か |
|---|---|
| **1 ロット検索** | ロット番号を入れて、ロット情報・引当・受注を見る。ここが出発点。「資材展開」で資材選択へ進む |
| **2 資材選択** | パレットとボードを決める。メインの画面。右側に **①パレットを決める → ②ボード → ③アングル → ④出す** の段が上から並び、その下に**実績パターン** |
| **3 簡易在庫** | 位置別の在庫を検索・受入・払出(旧UFMAP)。**検索 | 保管位置の図 | 在庫一覧 の3列**が同時に見えます(位置を押しても図は隠れません)。検索で当たった位置は**黄色**。資材モードにもあります(見る・受け入れまで)。**払い出しと配置編集は現場モードだけ**で、直した配置は資材モードにもそのまま出ます |
| **4 倉庫連携** | 資材への発注を送る・確かめる画面(送るのと取り消すのは現場モード、確認済みにするのは資材モード)。送った発注の一覧(送信履歴)とやり取り(コメント)もここ。共有フォルダが見えない間に送った発注には **「未送信」** が付き(倉庫にはまだ届いていない)、つながると自動で送られて消えます |
| **5 棚検索** | 棚の配置図と最寄り棚・疲労度の確認。検索で当たった置き場は**黄色**。置き場を押すと、右の列(検索の下)に**置き場の資材**が大きな字で出ます(図は隠れません) |
| **6 選定ログ** | 「なぜこのパレットが選ばれた/落ちたのか」の理由が1行ずつ出る |
| **7 設定** | 取り込みと書き戻し、置き場所、権限、パスワード、ボード人気度、**保存場所(このPCだけのもの・共有のもの)**。初回はここから |

資材選択の**真ん中**は「配置図」と「選定一覧」のタブです。

上の帯の右には「**? 説明書**」(写真入りの操作説明書が別の窓で開く)と「**◐ ライト / ダーク**」(画面の色の切り替え。このPCに残る)があります。

### 画面が縦に足りないとき

**画面そのものはスクロールしません。** 一覧(リスト)の中だけがスクロールします。
資材選択の右側の段は、**見出しを押すと開いたり畳んだり**できます。
畳んでも、決まったこと(例:「上用 2種 4枚 / 下用 2種 3枚」)は見出しの横に残ります。

## 5. 基本の流れ

### ① ロット検索でロットを選ぶ

**打つところは1つだけです。** いちばん上の「ロットを探す」欄に打ちます。

- **番号が分かっているとき** … 打つたびに一覧が絞れます。**1件に絞れても勝手には開きません**
  (有るかどうかだけ見たいときのため。VER4.8.7〜)。開くときは **Enter** を押します
- **番号が分からないとき** … 用途・材質・寸法などで絞ってから、
  目的の行を**ダブルクリック**(またはキーボードの **Enter**)で開きます

**詳細は画面の手前に開きます。** 閉じれば元の一覧がそのまま残り、次の行をすぐ開けます。
閉じるのは右上の「閉じる」か **Esc** キー、または枠の外を押します。
詳細の「**資材展開**」を押すと、製造板幅×板丈を製品サイズとして持って資材選択へ進みます。

一覧が多すぎるときは絞り込みます。

| やりたいこと | 操作 |
|---|---|
| 番号・用途・材質のどれかで探す | 上の「ロットを探す」に打つ(全部の列を横断します) |
| 材質や板厚で絞る | 「条件を追加」に打つ → 出てきた候補を選ぶ |
| 絞りを外す | 条件の右の **×**。全部外すなら「全解除」 |
| 並べ替える | 見出しを押す。もう一度押すと逆順(▲▼で分かります) |
| 毎日使う絞りを覚えさせる | 「+ この条件を保存」に名前を付ける。次からは名前を押すだけ |
| 一度に出す件数を変える | 右上の「表示件数」 |

仕掛一覧の「**引当有無**」の隣の「**引当数**」は、そのロットに付いている**引当の件数**です
(引当数量の合計ではありません。kg と枚が混ざっているため)。引当が無いロットは空欄です。

> **件数の見かた。** 「1551 件中 200 件を表示」と出ていたら、**まだ先が
> あります**。絞り込むか、表示件数を増やしてください。

### ② 資材選択でパレットを決める(①パレットを決める の段)

1. 「製品 幅・丈」には、資材展開した製品サイズが入っています。
   **一覧には、この製品が載るパレットだけ**が出ます(打ち直すとその場で絞り直します)。
   手で打つときは**片方だけでも**絞れます(VER4.7.6〜): 幅だけなら巾適合に、丈だけなら
   丈適合に収まるパレット、両方なら両方に収まるパレット(回転も見る)
2. 一覧から使う行を押して選びます。下に**単位・発注コード・当たり方**
   (回転あり/なし・厳密/+5mm・幅2山/丈2山)が出ます
3. 「**パレット決定**」を押します。**パレットと製品サイズが同時に確定**します
   (以前の「パレット検索」「適用」「セット」の3回は、この1回にまとめました)
4. 一覧に無い寸法を使うときは「**一覧に無い寸法を使う**」を開いて幅・丈を打ちます
5. 最初からやり直すときは「**やり直す**」。**ロットの選択ごと外れて**、何も選んでいない状態に戻ります(VER4.8.5〜)。
   パレット・製品サイズ・選んだボードとアングルと、ロットから立ったモード(1P1185 タイト限定・プロテック・
   1P0113 裸梱包・EX受注・上下共用)が全部外れます。疲労度優先・在庫考慮・EXまで表示は、自分で切るまで残ります。
   続けるときは、ロット検索からロットを選び直してください(包装仕様NOからモードを判定し直します)

> **発注コードと単位は、一覧で選んだ行からしか取れません。** 倉庫送信や
> Lot印刷で使うので、必ず一覧の行を選んで決めてください。

一覧の上のボタン:

| ボタン | 効果 |
|---|---|
| **EXまで表示** | 記号にEXを含むパレットも出します。**単位の条件(台、上下共用なら台・枚)は外しません** |
| **EXオンリー** | EXのパレットだけを出します。EX受注のロットを引いたときだけ押せます |
| **2山積** | 製品を2つ積む前提で探します(下の「2山積」) |

思ったパレットが出てこないときは、**選定ログ**を見てください。
「なぜその候補が落ちたのか」が1件ずつ書かれています。

#### 2山積

「2山積」を押してから一覧で行を選ぶと、その行がどう当たったかで**2山の向き**が決まります。

| 当たり方 | 意味 | 条件 |
|---|---|---|
| **幅2山** | 幅方向に2つ並べる(製品幅×2) | 桁数が奇数(スカシは桁数を問わない) |
| **丈2山** | 丈方向に2つ並べる(製品丈×2) | 業界がスカシ・タイトで、脚が3本以上 |

「パレット決定」を押すと、製品サイズは**2山分を1つの製品として**確定します
(表示に「※2山(幅170×2)」のように出ます)。上用の選定・配置、下用の補填、カバー表示、
切断依頼は、すべてこの2山分の大きさで動きます。

- **入力欄の製品 幅・丈は1山分のまま**です(2倍にすると次の絞り込みで4倍になるため)
- 2山積を押し直す・ロットを変える・実績を読み込むと、向きは決め直しになります。
  2山積なのに向きが決まっていないときは「※2山積(向き未決定→1山扱い)」と出て、1山として扱います

### ③ ボードを選ぶ(②ボード の段)

| ボタン | 何が起きるか |
|---|---|
| **ボード選定** | 自動でボードを選びます(疲労度優先がONなら「疲労考慮ボード」) |
| **疲労度優先** | 取り出し距離とカットの手間を加味して選びます(第8章) |
| **ボード配置** | 選んだボードの並べ方を真ん中の配置図に描きます |
| **在庫考慮** | 在庫の薄いボードに「▲薄」を付け、在庫のあるボードを優先します |
| **候補変更** | 別の考え方(敷き詰め方式)で選び直します(下の「候補変更(別案)」) |
| **上用へ追加 / 下用へ追加** | 一覧で選んだボードを手で足します(一覧にあるものだけ) |
| **クリア** | 選定結果と配置図を消します |

**配置図の見かた**

- 上用は赤系、下用は緑系。**細い補填材(100mm以下)は厚みの色**(30・50・100)で塗り、凡例が出ます
- 補填で置いた板でも、**100mmより太い板は上用・下用と同じ色**です
- **切る部分**はオレンジの斜線、**切る線**は赤。切り落とす部分はパレットの枠の中で止めて描きます
- 図の下の2行が**カバー表示**です(例:「幅OK　丈+15mm超」)。製品サイズと比べて、
  足りない(−)・超えている(＋超)・OK を出します。丈は**ボードを置き始めた位置から**数えます

#### 候補変更(別案)

現行の「ボード選定」とは別の考え方(**行を丈方向に積んで面を作る**)で選び直します。
押すたびに **A(枚数最小)→ B(種類最小)→ C(カット1枚許容)** と変わり、選定と配置まで入れ替わります。

- 中身が同じ候補は飛ばします(「候補C は候補A と同じ内容のため飛ばしました」と出ます)
- 上下そろって候補がある案を先に出します
- 上用は製品幅より**プラス禁止**、丈は**業界シリーズ(1×2・4×8 など)と同じ5mmまで**のマイナスを許します
- 現行の「ボード選定」はそのままで、押せばいつでも戻せます。プロテックでは使えません

#### 狭幅パレット

パレットや製品の幅が小さく、普通の板を置けないときは、**細い板を幅方向に並べて**覆います
(1本ずつを「帯」と呼びます)。考え方は **「パレット以下・製品以上」** です。

- 帯の板は**丸ごと使える枚数**だけ並べ、製品丈に足りない分は、いちばん薄い補填ボード
  (30→50→100)を「**丈補填**」として帯の端に1枚足します
  (例: 50×1600 で製品丈1615 → 30mm を1枚で 1630)
- 補填で足りない・パレットを超えるときだけ、同じ板をもう1枚足します
- 下用の帯は**製品丈で切り、パレット丈の中央に寄せ**ます。幅は**製品幅まで**埋めます(パレット幅は超えません)

### ④ 出す(④出す の段)

| ボタン | 何が起きるか |
|---|---|
| **Lot印刷** | Lot貼付用の帳票が別窓で開きます |
| **切断依頼** | 切断依頼書が別窓で開きます(下の「切断依頼」) |
| **配置図印刷** | 配置図とアングルを印刷用のページで開きます(配置してあるときだけ) |
| **倉庫送信** | 倉庫連携の画面へ移ります。**ここでは登録しません**。倉庫連携で中身を確かめてから送ります |
| **使用する** | 配置したボードの枚数を、製品・パレットの寸法と一緒に残します(ボード使用実績・人気度に積まれます) |
| **在庫を見る**(①の段の見出し) | 簡易在庫へ、決めたパレットの寸法を持って移ります(旧「パレットMAP」) |
| **置き場をまとめて見る** | 棚検索へ、選んだボードとアングルを持って移ります(旧「ボードMAP」) |

「置き場をまとめて見る」を押すと、棚検索で該当の置き場が一度に光り、**合計疲労度**が出ます。
上用と下用に同じサイズがあっても、**別々に数えます**。
置き場が登録されていない資材があれば「2件は置き場が未登録: …」と併せて出ます。

#### 切断依頼

切る板があると、押したときに「**丈カットを行いますか？**」と訊きます。

| 選ぶもの | 依頼書 |
|---|---|
| **丈カットあり** | 「幅カットのみ」と「幅＋丈カット」を分けて出します |
| **丈カットなし** | 丈カットの分を「幅カットのみ」にまとめて出します。**幅も切らないなら切るものが無いので、依頼書は作らず**「カットが必要なボードはありません」と出します |
| **キャンセル** | 出しません |

上用は**製品幅−20mm**、下用は**パレット幅ぴったり**で切ります。

**倉庫へ送る**(VER4.3.0〜): 紙を渡す代わりに、切断依頼書をそのまま倉庫へ送れます。

1. 切断依頼のプレビューの上の **「⇪ 倉庫へ送る」** を押す(担当・台数などを直したなら、直した紙面のまま送ります)
2. 倉庫連携の画面の **「送った切断依頼」** に並びます。状態は「倉庫はまだ開いていません」→「受け取った」→「切った」
3. 倉庫は **「届いた切断依頼」** で「開く」を押して紙面を見て、印刷します。**開くと「受け取った」**になります。
   切り終えたら「切った」を押します。レールの倉庫連携には、まだ開いていない数が「切N」と出ます

- **送った紙面は固まります。** あとで資材選択をやり直しても、**別のロットを検索しても消えません**。
  現場も「送った切断依頼」の「開く」から、いつでも開き直して印刷できます
  (プレビューで直した内容のほうは、これまでどおり別のロットを検索すると消えます)
- **取り消し**は送った端末だけ、**倉庫が受け取る(開く)前**だけできます。ほぼ同時に押して間に合わなかったときは、
  「先に倉庫が受け取っていたため取り消せませんでした」と出ます
- **同じロットをもう一度送る**と訊きます。倉庫がまだ開いていなければ「前のものを取り消して差し替えますか？」、
  もう受け取っていれば「別にもう1枚送りますか？」。差し替えた前のものは「送り直し済み」と出ます
- 相手の画面には、倉庫連携の見張り(15秒ごと)で届きます(2台で試して 9〜15秒)
- 倉庫連携の一覧は **「送った発注 / 受け取った発注」と「送った切断依頼 / 届いた切断依頼」のタブ**に分かれています
  (VER4.3.1〜)。**まだ見ていないものがあるタブは光り**、件数が出ます
  - 倉庫: まだ開いていない切断依頼の数「新N」
  - 現場: 送った依頼が「受け取った」「切った」に変わったのに、まだそのタブを見ていない数「更新N」(タブを開くと消えます)
  - 発注のタブ: 相手が書いた、まだ開いていないコメントの数「新N」

#### 倉庫連携(送る・確かめる・取り消す)

- 資材選択でパレットを決めた時点で、倉庫連携の入力欄に**下書き**ができています
- 「**倉庫へ送信**」で登録します。**複数行はまとめて1回で登録し、途中で失敗したら1行も残しません**
- 同じロットをもう送ってあるときは、送る前に知らせます
- **送った発注の一覧**(送信履歴)は「**送った発注**」の段です。期間(すべて・今日・1週間・1か月)で絞れます。ロットを引いていなくても見られます
- **取り消し**は現場モードだけ、**倉庫が確認する前**だけできます。取り消した発注は打ち消し線で残り、
  資材モード(倉庫側)には「現場で取り消されています(取消日時: …)」と出ます
- 行を押して開いた窓で**発注コードを押すとコピー**します。マウスを乗せると「クリックでコピー」、
  押すと**押したその場所に「コピーしました」**と出ます(VER4.2.1〜)
- 行の「**コメント**」で現場と倉庫がやり取りできます。印は2種類あります(VER4.1.0〜)
  - **新**: 相手が書いたもので、**自分がまだ開いていない**もの。**コメントを開けば消えます**
    (返事を書く必要はありません。窓を閉じるとすぐ一覧から消えます)
  - **倉庫が未読 / 現場が未読**(VER4.4.1〜。以前は「相手未読」): **自分が書いた**もので、
    **相手(現場⇔倉庫)がまだ開いていない**もの。相手が開くと **「✔既読」** に変わります(自分では消せません)
  - 1台のPCで現場モードと倉庫モードを切り替えて使う場合も、現場モードで書いたものは倉庫モードでは
    「相手から来たコメント」として「新」が付き、倉庫モードで開けば現場モードに「✔既読」が出ます
  - コメントを開くと、自分のコメントの下に「✔ 倉庫 ○○ が 10/03 14:22 に見ました」/
    「… 相手はまだ見ていません」が出ます
  - 書いたらすぐ、一覧のその行に「コメント N」が出ます(VER4.2.1〜)。相手の画面には、
    見張り(**15秒ごと**)で届きます。相手が開いたことも同じ間隔で届き、「相手未読」が消えます。
    発注の窓を開いている間は取り込みを待ち、閉じてから取り込みます

#### 実績パターン

- 同じパレットで過去に組んだ内容を**読込**で呼び出せます(認証は要りません)。
  保存したときの**選定と配置図がそのまま**戻ります(計算し直しません)
- 「**実績を保存**」は管理者認証が要ります(設定画面の「パスワード」タブ →「マスタ編集の認証」)
- 保存した実績は**全端末で共有**されます

## 6. 印刷について

VBA版は「Excelにシートを作って印刷」でしたが、Python版はExcelを使いません。
**帳票をHTMLで作ってブラウザで開き、ブラウザから印刷**します。

1. 「Lot印刷」「切断依頼」「配置図印刷」のどれかを押す
2. 別の窓で帳票(印刷プレビュー)が開く
3. 上の帯の **「印刷する」** を押す(**Ctrl+P** でも同じです)
4. 印刷ダイアログで用紙と余白を確認して印刷
5. 終わったら帯の **「閉じる」** で窓を閉じる

上の帯(「印刷する」「閉じる」と案内)は**紙には出ません**。
点線の欄(担当者・台数・期限日など)を直した直後に「印刷する」を押しても、
直した内容はそのまま残ります(別のロットを検索するまで)。

### 印刷ダイアログでの注意

- **用紙**: Lot貼付用は「A4・横」、切断依頼書は「A4・縦」、配置図は「A4・横」
- **余白**: 「なし」または「既定」。ここが大きいと紙面が縮みます
- **背景のグラフィック**: 網掛けや色を出したいときは有効にしてください
- 「PDFとして保存」を選べば控えを残せます

> 初回は**必ず1枚テスト印刷して、現物と寸法が合うか確認**してください。
> ブラウザの余白設定で数mmずれることがあります。ずれる場合はご連絡ください、
> 調整できます。

## 7. 配置図に写真を敷く(簡易在庫・棚検索)

VBA版は**フォームの背景に配置図の写真**を置き、その上にボタンやラベルを
実際の場所に合わせて並べていました。Python版も同じ作りです。

- **簡易在庫**タブ … 保管位置のボタン(S1・S2・A1〜A11・B1〜B5・C1〜C7・D1〜D3)
- **資材配置(棚検索)**タブ … 置き場のラベル

どちらの図にも **「背景画像...」** ボタンが付いています。

### 手順

1. 図の下にある **「背景画像...」** を押す
2. 写真を選ぶ → 図の幅に合わせて自動で縮小され、すぐ下に敷かれます
3. **大きさや位置が合わないとき**は、その右のボタンで合わせます

   | ボタン | 効果 |
   |---|---|
   | **拡大 / 縮小** | 写真だけを10%ずつ拡大・縮小します |
   | **← → ↑ ↓** | 写真だけを10ポイントずつ動かします |
   | **画面に合わせる** | 選び直した直後の状態に戻します |
   | **背景を消す** | 写真をやめます |

4. **ボタン(ラベル)の側**を動かしたいときは **「配置編集」** に
   チェックを入れて**ドラッグ**します
5. **「保存」** を押す

> **写真だけを動かすのか、ボタンだけを動かすのか**を意識してください。
> 写真の縮尺が現場と違うだけなら「拡大/縮小」で合います。
> 棚そのものが動いたのなら「配置編集」でボタンを動かします。

> **写真は PNG か GIF にしてください。** JPEGは読めません(Pythonの標準機能
> だけで動かすための制約です)。PowerPointの図なら、右クリック →
> **「図として保存」** で PNG にできます。

> 図が小さくて見にくいときは、図の上の **「＋」** で拡大してください
> (図は枠の中でスクロールします)。

### 位置が増えた・減ったとき

- **「位置を追加...」** … 図の中央に新しいボタンが出るので、ドラッグして
  実際の場所へ動かし「保存」
- **「選択した位置を削除」** … 図でボタンを押して選んでから削除

図の下の帯に **「在庫にあるのにマップに無い位置: ○○」** と出ていたら、
その位置は図から押せません。「位置を追加...」で足してください。

> **元に戻したいとき**は「出荷時の配置に戻す」を押します。編集内容は
> `data/pallet_map.json`(簡易在庫)と `data/floor_plan.json`(棚検索)に
> 入っているので、このファイルを消しても元に戻ります。
> **座標はプログラムの中には書かれていません。** 置き場が変わっても
> プログラムを直す必要はありません。

## 8. 自動で切り替わるモード

ロットを引くと、受注の**包装仕様NO**を見て画面が自動的に変わります。
いま何のモードかは、**操作パネルのいちばん上の帯**に出ます。

| 帯の表示 | 何が起きているか |
|---|---|
| (なにも出ない) | 通常モード |
| 【1P0113 裸梱包モード】 | パレット欄が消え、溝切角材と松板の必要数を出す欄に変わります |
| 【プロテックボードオーダー選択中】 | ボード種別が自動で「プロテックボード」に変わります |
| 【EXオーダー選択中】 | EX受注です。パレット一覧のEX対象行に色が付きます |

このほか、**保護材がアングル以外(ザラ板など)に確定した**ときは、
上用の欄とアングルの欄が消えて、下用の見出しが
**【上下共用ボード配置】**に変わります。上用は下用と同じ板を使う、
という意味です。

### 手で切り替えるモード

| 場所 | 名前 | 効果 |
|---|---|---|
| ①の段、一覧の上 | **2山積** | 押すたびに切り替わります。2山積のときは一覧が2山前提になり、決めたパレットの当たり方で2山の向きが決まります(第5章「2山積」) |
| ②の段 | **疲労度優先** | 押すと紫になり、以降のボード選定とアングル自動選定が疲労度優先になります。**もう一度押すまでONのまま**で、ロットを変えても消えません |
| ②の段 | **在庫考慮** | 押すたびに切り替わります。ONのときは在庫の薄いボードに「▲薄」が付いて在庫のあるボードが優先されます |
| 右側のいちばん上 | **1P0113 強制** | 包装仕様NOが取れないロットでも、押せば裸梱包モードにできます。新しいロットを引くと自動で解除されます |

> **疲労度優先**は「カットするくらいなら遠くから運ぶ」という現場ルールを
> 反映したものです。カットが必要な組み合わせは大きく不利に評価されます。
> ONのあいだは**「ボード選定」ボタンの字が「疲労考慮ボード」**に変わるので、
> いまどちらで選定されるのかがボタンを見れば分かります。

### ボタンの色の意味

ボタンの色は**操作の種類**を表しています。同じ色なら同じ種類です。

| 色 | 意味 | 例 |
|---|---|---|
| 深緑(塗り) | 別の画面へ移る | 置き場をまとめて見る / 在庫を見る |
| 青(塗り) | 実行 | ボード配置 / アングル配置 |
| 茶(塗り) | 印刷 | Lot印刷 / 切断依頼 / 配置図印刷 |
| 橙(塗り) | 選定・決定 | パレット決定 / ボード選定 |
| 赤(塗り) | 送信・保存(残る操作) | 倉庫送信 / 使用する / 実績を保存 |
| 緑(枠だけ) | 探す・読み直す | 最新にする / アングル自動選定 |
| 赤(枠だけ) | 消す・取り消す | やり直す / クリア / 取り消し |
| 紫 | 疲労度優先 | ONで塗り |

**「製品サイズ: 未設定」がピンク色の帯**で出ているあいだは、まだ確定していません。
ここを見落とすと以降の操作が全部空振りします。

保護材がアングル以外(ザラ板など)に確定すると、アングルの段が消えて
代わりに**「使用保護材: ザラ板」**と出ます。
段が消えたのは故障ではなく、上用が下用と同じ板になったという意味です。

## 9. 管理者向け

設定画面の「**パスワード**」タブ →「**マスタ編集の認証**」でパスワードを入れると、
資材選択の「実績を保存」やマスタの編集が使えるようになります。

**拠点**(L1 / HVC / LVC)は設定画面の「動作」で選びます。この設定は**疲労度の計算・
棚検索・アングル選定で共通に使われる1つの値**で、次回起動時にも残ります。

### 決め打ちの値(許容値など)を確かめる

許容値などのうち、**マスタ(DB)ではなくプログラムに書いてある値**は
**[決め打ちの値一覧.md](決め打ちの値一覧.md)** にまとめてあります
(例: 上用の幅マイナス許容 80mm、別案の上用の丈マイナス許容 5mm、パレット検索の許容差 ±5mm)。
一覧はプログラムから値を読んで作っているので、プログラムと食い違いません。

### パスワードを変える (VER2.4.0〜)

設定画面の **「動作」** タブに「管理者パスワード」があります。
**いまのパスワードを入れないと変えられません** ── 肩越しに見ていた人が
勝手に変えられないようにするためです。

- 4文字以上。確認用にもう一度入れます
- 一度も変えていない端末は、これまでどおりのパスワードで通ります
- 変えたかどうかは「変更済み」「既定のまま」で見えます。**値そのものは
  画面にもファイルにも出ません**(撹拌して保存します)
- **忘れたときは**、ツールのフォルダの中の `data\user_config.json` の
  `admin_password` の行を消すと既定に戻ります(このPCだけの設定ファイルです。第10章)

このパスワードは「押し間違いを防ぐ」ためのものです。誰がその端末で
何をできるかは**アクセス権限マスタ**が決めます(設定画面の「いまの状態」)。

---

### 配布する前に設定を決めておく(配布設定, VER2.90.0〜)

1台で設定を済ませて、その設定ごと配れます。配った先では**起動したときに
自動で読み込む**ので、1台ずつ設定画面を開いて打ち直す必要はありません。

1. 一度起動して、設定画面の「取り込み元」「動作」「パスワード」を決める
2. 設定画面の **「配布設定」** の面を開く
3. 配る項目を選ぶ(既定で、拠点以外が選ばれています)。配置図も配るなら
   「棚検索の配置図」「簡易在庫の保管位置マップ」も選ぶ
4. 管理者パスワードを入れて **「配布設定を書き出す」**
5. ツールのフォルダの直下に **`配布設定\`** ができます(通知に**できた場所**を出します)。
   配布用フォルダを作って配ってください(次の「配布用フォルダを作る」。`配布設定\` も一緒に入ります)
   - **フォルダができないとき**は、通知と「書き出す」の下に理由が出ます。よくあるのは
     ①パスワード違い ②選んだ設定がこの端末で**どれも変えていない**(既定のまま) ──
     このときは「フォルダは作っていません」と出ます。配置図を選べば配置図だけでも書き出せます
     ③フォルダに書く権限が無い・ファイルを開いている(場所と理由が出ます)

**配布先に関わるものは、すべて `配布設定\` に入ります。**

```
配布設定\
  設定.json          置き場所・図面URL・自動取り込み・書き出し先・管理者パスワード
  配置図\
    floor_plan.json  棚検索の配置図(選んだときだけ)
    pallet_map.json  簡易在庫の保管位置マップ(選んだときだけ)
  はじめに読む.txt   何が入っているか・配った先で何が起きるか
```

| | 扱い |
|---|---|
| 拠点 | **既定で入れません。** ラインごとに違うので、配った先の「動作」で選ぶ |
| 管理者パスワード | 撹拌した値が入ります(平文は入りません) |
| この端末で変えていない項目 | 入れません。配った先も同じ既定で動きます |
| 配置図 | この端末で保存した配置、無ければ出荷時の配置を入れます |

**配った先での読み込み**

- 起動したとき、`配布設定\` があれば読み込みます
- 無い項目・**空の項目**は埋めます
- **書き出し直した配布設定を置くと**、前の配布設定のまま変えていない項目
  (配置図も)は新しい値に入れ替わります。配り直せば揃います
- **その端末で変えた設定・保存した配置図は上書きしません。** 読んだあとに
  端末で直した値が、次の起動で戻されることはありません
- 揃えたいときは「配布設定を読み込み直す」(すでにあるものも上書き)
- 配置図だけ差し替えたいときは、`配布設定\配置図\` の中の .json を置き換える

書き出す・読み込み直す・消すには、**管理者パスワード**が要ります。
`data\` は配らないでください(`packaging_tool.db` は端末ごとの中身です)。

### 配布用フォルダを作る(VER2.88.0〜)

配るものだけを新しいフォルダへ写します。手でコピーすると `data\`(端末ごとの
手元のDB・設定)や `tests\` が紛れるので、こちらを使ってください。

1. 設定も配るなら、先に設定画面の「配布設定」で書き出しておく
2. `scripts\make_dist.bat` をダブルクリック(または
   `python scripts\make_dist.py`)
3. ツールのフォルダの隣に **`梱包資材総合ツール_VER版`** ができます。
   これを配ってください。中の **`配布メモ.txt`** に、入れた配布設定と
   配った先ですることが書いてあります

| 付けるもの | すること |
|---|---|
| `--out 場所` | 作る場所を決める |
| `--zip` | zip も作る |
| `--no-settings` | 配布設定を入れない |
| `--force` | 作る場所に前の中身があれば消して作り直す |

- ツールのフォルダの中には作りません(次に作るとき、前のものまで写すため)
- 中身のある場所には、`--force` を付けないかぎり作りません
- 作ったあと、`data\`・`tests\` などが入っていないことを確かめ、入っていたら
  作るのをやめます

## 9.5 選定ログを後から追う (VER2.4.0〜)

選定ログは**日ごとのファイルにも残ります**。アプリを閉じても消えないので、
「先週のあのロット、なぜあの候補になったのか」に後から答えられます。

選定ログの画面に**日付の一覧**が出ます。開く前に、その日が何行で誰が
動かしたのかが分かります。日付を押すと、その日の中身が出ます。

1行ごとに **いつ・どの端末の誰が** を持っています(画面には大きく
出しません ── 作業中に読むものではないからです)。

| | |
|---|---|
| 置き場所 | `%LOCALAPPDATA%\PackagingTool\logs\selection\2026-08-09.jsonl` |
| 残す期間 | 60日。古い日は起動時に消え、消したことはアプリのログに残ります |
| 画面の「クリア」 | **ファイルは消えません。** 画面を片付けるだけです |

## 9.6 エラーを後から追う・なぜなぜで分析する (VER3.6.0〜)

エラーは**エラー番号**付きで残ります。画面に出たエラーにも同じ番号が出ます
(例: `思わぬエラーが起きました(エラー番号 E261001-142233-a1)`)。
番号の頭は**起きた日時**(26年10月01日 14:22:33)なので、口頭で聞いてもいつのことか分かります。

**「遅い」と感じたら**(VER4.1.0〜): 設定画面「ログ」の面の **「時間のかかった操作(今日)」** に、
1秒以上かかった操作が**起動から何秒後・その画面を何回目に開いたときか**付きで出ます。
画面ごとに「起動して最初の1回だけです」/「2回目以降にもあります」とまとめて出るので、
初回だけ遅いのか毎回遅いのかが、その端末の記録で分かります。

**見る場所: 設定画面の「ログ」の面**

1. 「エラー記録」に、新しい順にエラーが並びます(エラー番号・文言・端末名で絞り込めます)
2. 行を押すと中身が出ます
   - いつ・どの端末で・どの操作で・そのときの入力・開いていた画面
   - **直前の動き**(エラーの前に何をしていたか。新しいものが下)
   - **この操作の全部の行**(同じ操作番号の行。選定の細かい判断まで入ります)
   - エラーの中身(開発担当向け)
3. **「なぜなぜの下書きをコピー」**を押すと、上の内容に「なぜ1〜5・対策」の欄を付けた
   文章がコピーされます。報告やなぜなぜ分析の紙にそのまま貼れます

**何が残るか**

| 残るもの | 中身 |
|---|---|
| 操作の足跡 | 画面の操作1つにつき1行(何を押したか・入力・結果・かかった時間)。断ったときは**断りの理由**も |
| 操作番号 | 1つの操作の間に出た行すべての頭に `[番号]`。番号で引けば、その操作で何が起きたかを通しで読めます |
| エラー記録 | 思わぬエラー・**画面(ブラウザ)の中のエラー**・取り込みなど長い処理の失敗。エラー番号付き |

パスワードは残しません(`(伏せます)` になります)。写真など長いものは縮めて残します。

**ログの出力先を変える**(管理者パスワードが要ります)

設定画面「ログ」の面の「ログの出力先」で、フォルダを指定できます。

- 指定したフォルダの下に**その端末の名前のフォルダ**を作って書きます。共有フォルダを
  全端末で指しても混ざらず、エラー記録の「ほかの端末のぶんも見る」で**全端末のエラーを1か所で**見られます
- **書けないフォルダは保存しません。** 起動したときに書けなければ(共有に届かない日など)、
  既定の場所に書いて、その面に理由を出します。途中で書けなくなったときも既定の場所へ戻して書き続けます
- 空にして保存すると既定(`%LOCALAPPDATA%\PackagingTool\logs`)に戻ります
- **この端末だけ**の設定です(配布設定には入りません)

| 残す期間 | |
|---|---|
| 動作ログ `packaging_tool_日付.log`・取り込み診断 | 90日 |
| エラー記録 `エラー記録_年月.jsonl` | 24か月 |

古いものは起動時に消え、消したことはログに残ります。

## 10. 困ったときは

| 症状 | 見るところ |
|---|---|
| パレットが出てこない | **選定ログタブ**。除外理由が1件ずつ出ています |
| 製品より小さいパレットが出た | 出ません。適合範囲が現物より広い行は選定ログに `×除外: ...` として出ます。取り込みのたびに適合範囲を計算し直すので普通は起きませんが、気になるときは設定画面の **「適合範囲を再計算」** を押してください |
| ロット検索が空 | 設定画面で仕掛台帳を取り込んでください(第3章) |
| Accessに反映されない | 設定画面で `書き戻し: 可能` になっていますか。ドライバが無いと送れません(第3章) |
| ボード候補が空 | ボード種別が合っていない可能性があります。プロテックモード中は候補が3種類しかありません |
| 倉庫送信が押せない | パレット一覧の行を選んで「パレット決定」を押しましたか(発注コードの取得元です) |
| 切断依頼が「依頼は不要」と出る | 選定結果にカットの記録がありません。カットが要らない組み合わせです |
| 切断依頼で「カットが必要なボードはありません」 | 「丈カットなし」を選び、幅も切らない組み合わせです。切るものが無いので依頼書は作りません |
| 許容値がいくつだったか分からない | [決め打ちの値一覧.md](決め打ちの値一覧.md) を見てください |
| エラー番号が出た | 設定画面の **「ログ」の面**で番号を入れて絞り込み、中身を見てください。「なぜなぜの下書きをコピー」で報告に貼れます(9.6) |
| 動きがおかしい | 動作ログを送ってください。場所は設定画面の **「ログ」の面**の「いま書いている場所」です(既定は **`%LOCALAPPDATA%\PackagingTool\logs`**。エクスプローラのアドレス欄にそのまま貼り付けると開きます)。日付の新しいファイルをお願いします |

### このPCだけのもの と 複数のPCで共有するもの

ファイルには**2種類**あります。**設定画面の「保存場所」の面**に、いまの実際の場所つきで出ています。

| 種類 | どこにあるか | PCを替える・版を入れ替えるとき |
|---|---|---|
| **このPCだけのもの**(このPCで引き継いで使う) | ツールのフォルダの中の `data` フォルダ、と `%LOCALAPPDATA%\PackagingTool`(ログ・作業用) | **持っていく必要があります**(とくに `data` フォルダ) |
| **複数のPCで共有するもの**(取り込み元) | 共有フォルダ(梱包資材マスタ・仕掛台帳・看板マスタ・パレット閾値マスタ) | 持っていかなくてよい。新しいPCで「取り込み元」の場所を合わせるだけ |

**共有するもの**のうち、このツールが書き込むのは **梱包資材マスタ** だけです
(倉庫への発注・受払の履歴・ボード使用実績・発注コメント・実績パターン)。
どのPCも書き戻しで送り、取り込みで受け取るので、全PCで同じものが見えます。
仕掛台帳・看板マスタ・パレット閾値マスタは読むだけです。

**このPCだけのもの**は次のとおりです。ほかのPCには届きません。

| ファイル | 中身 | 無くなったら |
|---|---|---|
| `data\user_config.json` | 取り込み元・書き出し先・ログの出力先の置き場所、拠点、自動取り込み、管理者パスワード、よく使う条件 | **設定し直し**(置き場所は管理者パスワードが要る) |
| `data\floor_plan.json` | 棚検索の配置図(**背景の写真もこの中**) | **配置編集をやり直し** |
| `data\pallet_map.json` | 簡易在庫の保管位置マップ(**背景の写真もこの中**) | **配置編集をやり直し** |
| `data\packaging_tool.db` | 取り込んだマスタ・仕掛台帳の写し、選定の記録、発注・受払・使用実績・コメントの控え、コメントの既読 | 取り込めば戻る(**まだ共有へ送れていない発注・受払・使用実績・コメントは戻らない**) |
| `%LOCALAPPDATA%\PackagingTool\logs` | 動作ログ(90日)・エラー記録(24か月)・選定ログ(60日)。**動作ログとエラー記録は設定の「ログ」の面で出力先を変えられます**(共有フォルダを指せば、ほかのPCからも見られる) | 無くても動く |
| `%LOCALAPPDATA%\PackagingTool` のほかのフォルダ | 一時ファイル・表を持ってくる前のバックアップなど | 無くても動く |

**バックアップは `data` フォルダごと**コピーしてください。手で作った配置図と
設定は取り込みでは戻りません。

> **新しい版に入れ替えるときは `data` フォルダを持っていってください。**
> 配布物には `data` が入っていないので、新しいフォルダに入れ直すと、
> 置き場所も配置図も出荷時に戻ります。古いフォルダの `data` を、新しい
> フォルダへそのままコピーすれば引き継げます。

> **ログの置き場所が変わりました。** 以前はツールのフォルダの中の `logs/` でしたが、
> **`%LOCALAPPDATA%\PackagingTool\logs`** に移りました。
> ツール本体を共有フォルダに置いて複数の端末から使うと、本体側に書いたログが
> 端末どうしで混ざってしまうためです。`data` フォルダ(DB・設定・配置図)の
> 場所は**変わっていません**(ツールのフォルダの中のまま)。

## 11. 運用前の確認

### 11.1 選定と配置が変わっていないこと

選定・配置は業務の心臓部で、**1行変えれば現場の発注が変わります**。
手を入れたあとは、41通りの実データで結果が変わっていないことを
機械的に確かめてください。

```bat
python scripts\compare_ui.py
```

`一致しました` と出れば、計算は変わっていません。
差分が出たときは、**そのロットの作業を止めて**開発担当へ連絡してください。

### 11.2 印刷は実機で1枚出して確かめる

帳票は画面上では正しく見えても、**紙に出したときの実寸**は
プリンタとブラウザの設定で変わります。運用を始める前に、
**現場で実際に使うプリンタで1枚**出して確かめてください。

1. ロット検索でロットを引く
2. 資材選択で「Lot印刷」を押す(別の窓が開きます)
3. 上の帯の「印刷する」(または `Ctrl+P`)で印刷。**倍率は「100%」**、「用紙に合わせる」は**外す**
4. 出てきた紙をラベルの貼付位置に当て、はみ出さないか見る
5. 切断依頼も同じ手順で1枚出す

> 倍率が「用紙に合わせる」のままだと数mm縮みます。出た紙が合わない
> ときは、まず倍率を確かめてください。

### 11.3 配置図を編集していた場合

棚検索の「配置編集」で動かした置き場は、**ツールのフォルダの中の**
`data\floor_plan.json` にあります(簡易在庫は `data\pallet_map.json`)。
おかしくなったら **「出荷時に戻す」** を押せば、出荷時の配置に戻ります。
出荷時の配置は、現場で仕上げた配置と背景写真です(VER2.89.0〜)。

### 11.4 うまく動かないときに集めるもの

開発担当へ連絡するときは、**エラー番号**と、設定画面「ログ」の面の
「なぜなぜの下書きをコピー」の文章を添えてください。あわせて、同じ面の
「いま書いている場所」(既定は `%LOCALAPPDATA%\PackagingTool\logs`)の
新しいファイルがあれば、何が起きたかを通しで追えます。
